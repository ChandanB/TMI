Subsequent blocking categories:

  EnvironmentKey defaults instead of composition-root injection.
- ProductionIntegration used four MainActor singleton EnvironmentKey defaults.

  non-Sendable DocumentID wrapper into Sendable domain values.

Resolution summary:
- Added checked Sendable constraints to generic async validation helpers.
- Replaced shared EnvironmentKey service defaults with composition-root
  dependency injection.
- Isolated UI-facing services and mutable state while keeping pure domain values
  explicitly nonisolated under the app target's MainActor default.
- Removed Firestore DocumentID wrappers from Student, TMIPlan, TMIUser,
  AppNotification, PlanEvidenceEntry, PlanInputField, and RecentActivity domain
  values; repository decoders remain responsible for injecting document IDs.
- Replaced unchecked Interest reference semantics with a checked Sendable value
  type so TMIPlan and Student are transitively checked Sendable.
- Removed all nonisolated(unsafe) declarations used by the Task 11 baseline.
- Updated concurrent keychain/storage tests to capture Sendable dependencies
  instead of their XCTestCase instances.
- Marked the macOS image compatibility scale constant nonisolated after the
  macOS compiler identified the cross-platform shim.
- Made the unit-test host genuinely multiplatform and selected the macOS app
  executable path when TMITests runs on macOS.
- Kept production Firebase composition explicit and hermetic tests fail-closed;
  no shared notification or audit dependency is created by an EnvironmentKey.
- Preserved the 36 existing Firebase timeout boundaries with checked-Sendable
  results, and restored concurrent StudentContext edge prefetch without mutable
  cross-actor captures.
- Replaced Firestore callback continuations used for ordinary model writes with
  documented offline local-enqueue helpers, while restoring canonical document
  IDs at repository decode boundaries.
- Hardened secure storage for synchronizable items, migrated both historical
  cryptographic-key tag representations before key generation, and excluded the
  device master key from device-bound backup payloads.
