# "Create My Plan" Button Implementation

## Overview

Implemented the functionality for the "Create My Plan" button in the Career Path Detail View, which creates a TMI Plan based on a selected career path.

## Changes Made

### File: `TMI/Views/Survey/CareerExplorationView.swift`

#### 1. Added Imports (Lines 9-10)
```swift
import FirebaseFirestore
import FirebaseAuth
```

#### 2. Added State Variables (Lines 273-274)
```swift
@State private var isCreatingPlan = false
@State private var showingPlanCreated = false
```

#### 3. Updated Action Button (Lines 440-477)
**Features:**
- Shows loading indicator while creating plan
- Disables button during creation
- Displays success alert when plan is created
- Offers "View Plan" and "Done" actions

```swift
Button(action: {
    Task {
        await createPlanFromCareer()
    }
}) {
    HStack {
        if isCreatingPlan {
            ProgressView().tint(.white)
        } else {
            Image(systemName: "sparkles")
            Text("Create My Plan")
        }
    }
}
.disabled(isCreatingPlan)
.alert("Plan Created!", isPresented: $showingPlanCreated) {
    Button("View Plan") { dismiss() }
    Button("Done") { dismiss() }
}
```

#### 4. Implemented Plan Creation Logic (Lines 479-565)

**Main Function: `createPlanFromCareer()`**
- Fetches the student from Firestore
- Creates a TMI Plan with career-specific data
- Saves plan to Firestore
- Shows success feedback

**Helper Functions:**

**`createGoalsFromCareer()`**
- Converts career pathway goals to TMI goals
- Takes up to 3 beginner-level goals
- Sets target date to 1 month from creation
- Returns array of Goal objects

**`createStrategiesFromCareer()`**
- Extracts strategies from career pathway
- Takes strategies from first 2 beginner goals
- Limits to 5 total strategies
- Returns array of strategy strings

## How It Works

### User Flow:
1. User completes Career Explorer survey
2. Views career matches and selects a career
3. Reviews career details (pathway, goals, TMI modules)
4. Taps "Create My Plan" button
5. **NEW:** Plan is created and saved to Firestore
6. **NEW:** Success alert appears
7. User can view the plan or dismiss

### Plan Structure Created:
```swift
TMIPlan(
    title: "{Career Title} Career Plan",
    model: {First TMI Module from pathway},
    primaryStudent: {Fetched Student},
    goals: {Converted from career pathway},
    interests: [], // Empty for now
    strategies: {Extracted from career pathway},
    createdAt: Date(),
    updatedAt: Date()
)
```

### Example:
For "Podcaster" career:
- **Title:** "Podcaster Career Plan"
- **Model:** "Chase Your Space" (from pathway.tmiModules)
- **Goals:** First 3 beginner goals from podcaster pathway
- **Strategies:** Up to 5 strategies from beginner level

## Data Mapping

### Career Pathway Goals → TMI Goals

| CEPGoal (Career) | Goal (TMI Plan) |
|------------------|-----------------|
| title | title |
| strategies[0] | description |
| estimatedDuration | (not mapped) |
| - | targetDate: +1 month |
| - | completed: false |

### Career Pathway → TMI Strategies

- Takes strategies from first 2 beginner-level career goals
- Limits to 5 total strategies
- Direct string mapping

## Firestore Path

Plans are saved to:
```
users/{userId}/tmiPlans/{autoGeneratedId}/
```

## UI States

### 1. Default State
- Button shows: "✨ Create My Plan"
- Button is enabled
- Career color as background

### 2. Creating State
- Button shows: Loading spinner
- Button is disabled
- Same career color background

### 3. Success State
- Alert appears: "Plan Created!"
- Message: "Your TMI Plan for {Career} has been created successfully!"
- Two action buttons: "View Plan" | "Done"
- Both dismiss the career detail view

## Error Handling

Current implementation:
- Prints errors to console
- Fails silently (no user-facing error message)
- Button re-enables after error
